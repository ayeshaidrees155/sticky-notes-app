# Sticky Notes App

A clean, interactive, and responsive Sticky Notes web application built with Vanilla JavaScript, HTML, and CSS. It allows users to create, manage, and persist notes seamlessly using the browser's Local Storage.

---

## Features

- **Interactive Note Management:** Create and delete sticky notes dynamically.
- **Local Storage Persistence:** Your notes stay saved even if you refresh or close the browser.
- **Stylized UI:** Features a tilted tape header design and responsive layout.
- **Smooth Interactions:** Hover zoom effects for an engaging user experience.

---

## Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styling, layout, and visual effects.
- **JavaScript (ES6+):** DOM manipulation, event handling, and state persistence.
